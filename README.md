# SSPT
**SSPT** is a simple stellar population (SSP) module for [CIGALE](https://cigale.lam.fr/) [(M. Boquien et al. 2019)](https://doi.org/10.1051/0004-6361/201834156) implementing temperature-dependent stellar initial mass functions.

SSPT and its associated stellar population library is described in **G. B. Bowling et al. (2026)**, link coming soon.

## SSP libraries
The precomputed SSPT stellar population library are hosted on Harvard Dataverse: [link, current version: v1](https://dataverse.harvard.edu/dataverse/sspt)

The library spans:
- Effective star-forming gas temperatures from 20 K to 80 K in 1 K steps
- Stellar metallicities of 0.0004, 0.0012, 0.008, 0.02, and 0.05
- SSP ages from 1 Myr to 13.7 Gyr in 1 Myr steps
